# بوابة الحلول المبتكرة — Business & Financial Advisory

موقع مؤسسي لشركة **ISG (بوابة الحلول المبتكرة — Business & Financial Advisory)**، المتخصصة في الاستشارات المالية والتجارية التنفيذية. يعمل الموقع على بناء الثقة، تأهيل الزائر، وتحويله إلى طلب اجتماع وجلسة تشخيصية.

## Technical Overview

مشروع **Next.js 15** مبني بتقنية App Router، يعمل بلغة JavaScript/TypeScript، ويهدف إلى تقديم الهوية المؤسسية للشركة بواجهة عربية كاملة (RTL) من غير أي ذكاء اصطناعي.

## ملاحظة مصدر المحتوى

كل النصوص المعروضة في الموقع منقولة حرفياً من ملف الهوية المؤسسية المعتمد `ISG_Website_Build_Prompt_v3.md`. لا تُضاف صياغات تسويقية جديدة دون الرجوع إلى العميل، ويمثّل هذا الملف المرجع الوحيد للمحتوى.

## حدود النسخة الحالية (MVP)

- قوالب المحتوى مبنية داخل الكود في `lib/content.ts` لتوسيع لاحق إلى نظام إدارة محتوى (CMS). أي تعديل على المحتوى الحالي يتطلب تعديلاً في الكود ثم إعادة البناء.
- نموذج التواصل يتحقق من المدخلات، ويحفظ الطلب في قاعدة بيانات PostgreSQL على Railway، ويرسل بريداً كاملاً إلى فريق العمل عبر قناة Brevo أو Resend حسب متغيرات البيئة (التفاصيل في `docs/INTEGRATIONS.md`).
- وصايا الصفحات القانونية (السياسات) صياغة أولية وتحتاج مراجعة قانونية، لا سيما وفق نظام حماية البيانات الشخصية (PDPL) السعودي.
- لا توجد صور أو شعارات رسمية بعد؛ الموقع يعتمد على المساحات البيضاء والطباعة فقط.
- لا يوجد أي ذكاء اصطناعي أو روبوت محادثة (chatbot) في الموقع؛ كل المنطق حتمي وقابل للمراجعة.

## البنية (Structure)

شجرة مختصرة للمشروع:

```
isg-website/
├── app/            # صفحات وتوجيهات Next.js App Router
├── components/     # مكوّنات الواجهة
├── lib/            # منطق المحتوى والنماذج والتقييم
├── docs/           # الوثائق التقنية ومعايير التكامل
└── tests/          # اختبارات الوحدة
```

## قرارات التصميم (Design Decisions)

- تخطيط عربي كامل من اليمين إلى اليسار (RTL).
- خط IBM Plex Sans Arabic للواجهة.
- لوحة ألوان: كحلي عميق مع ذهبي محدود الاستخدام.
- مساحات بيضاء واسعة وقوالب نظيفة.
- بلا صور جاهزة (stock photos) وبلا أرقام إحصائية وهمية.
